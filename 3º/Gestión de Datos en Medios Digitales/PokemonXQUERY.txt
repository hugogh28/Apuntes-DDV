//AGRUPAR POR TIPO
 
for $tipo in distinct-values(/pokedex/pokemon/tipos/tipo)
return
  <tipo name="{$tipo}">
    {
      for $p in /pokedex/pokemon[tipos/tipo = $tipo]
      order by $p/nombre
      return <pokemon>{data($p/nombre)}</pokemon>
    }
  </tipo>
  
NOTA: La función data() extrae el valor atómico (El texto entre etiquetas) de ese nodo.
  
//AGRUPAR POR TIPO CON GROUP BY Y USANDO EL BUCLE FOR

for $p in /pokedex/pokemon
for $t in $p/tipos/tipo
group by $tipo := data($t)
order by $tipo
return
  <tipo name="{$tipo}">
    { string-join($p/nombre ! data(.), " ") }
  </tipo>

NOTA: 

---- ! aplica la expresión de la derecha a cada elemento de la secuencia de la izquierda.

---- . significa "el ítem actual" (el nodo/valor en el que estoy).

---- data(.) extrae el valor atómico (El texto entre etiquetas) de ese nodo.

//AGRUPAR POR GENERACION

for $gen in distinct-values(/pokedex/pokemon/@generacion)
order by xs:integer($gen)
return
  <generacion num="{$gen}">
    { /pokedex/pokemon[@generacion = $gen]/nombre }
  </generacion>
